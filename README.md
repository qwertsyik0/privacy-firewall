# Privacy Firewall

Локальный плагин конфиденциальности для exteraGram и совместимых клиентов.

**Текущая версия:** `0.6.8`

## Возможности

- проверяет исходящий текст перед отправкой;
- находит телефоны, почту, ФИО, документы, банковские данные, пароли, токены и коды подтверждения;
- скрывает GPS-координаты, ссылки на карты, адреса, улицы, дома, квартиры, города, сёла и посёлки;
- проверяет содержимое PDF, Office и текстовых файлов;
- предупреждает при отправке данных незнакомым пользователям, ботам, группам и каналам;
- поддерживает доверенные чаты, профили защиты, разные стили маскирования и локальную статистику;
- не анализирует и не изменяет изображения;
- не отправляет проверяемые данные на сторонние серверы.

## Установка

1. Скачайте [`privacy_firewall.plugin`](privacy_firewall.plugin).
2. Откройте файл через exteraGram.
3. Включите плагин и перезапустите клиент.

## Совместимость

- exteraGram: `>= 12.5.1`
- Plugin SDK: `>= 1.4.3.3`
- Python-зависимость: `pypdf>=5.0`

## Аватар

Плагин использует первый стикер из набора:

```python
__icon__ = "teststiofgu/0"
```

## Конфиденциальность

Проверка выполняется локально. Плагин не делает собственных сетевых запросов и не сохраняет тексты сообщений или найденные значения. Локальная статистика содержит только числовые счётчики.

## Основные файлы

- [`privacy_firewall.plugin`](privacy_firewall.plugin) — готовый установочный файл;
- [`privacy_firewall.py`](privacy_firewall.py) — открытый исходный код;
- [`CHANGELOG.md`](CHANGELOG.md) — история изменений;
- [`SECURITY.md`](SECURITY.md) — правила безопасного сообщения об уязвимостях.
